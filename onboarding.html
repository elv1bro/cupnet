CupNet is a developer browser with a built-in MITM proxy, TLS fingerprinting, traffic logging, and rules.

  • Record HTTP(S) to SQLite and export HAR
  • Proxy profiles, DNS overrides, and per-tab isolation
  • Credentials vault and notes for your workflow

CupNet uses a local root CA to decrypt HTTPS for logging. The app trusts it automatically.

On other devices (phone, another PC) that route through this proxy, install the PEM file from Settings → Certificate or use Download certificate there.

Treat this CA like a password — anyone who trusts it can intercept TLS for you.

The default traffic mode routes browsing through the local MITM proxy. You can switch Direct or connect a proxy profile in Proxy Manager.

Use MITM bypass domains in Settings when a site breaks with interception.

Open Network Activity from the toolbar to record and inspect requests.

Vault stores logins; the address bar shows suggestions from your log; type > (or Ctrl+K / Cmd+K) for commands.

Press Settings in the toolbar for filters, bypass, and integrations.
