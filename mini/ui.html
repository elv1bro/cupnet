DNS overrides

Send a host to another IP without touching the system hosts file. CupNet keeps the URL, so the TLS SNI, the Host header and HTTP/2 stay those of the real site — only the TCP connection goes to the override (like curl --connect-to). Tunnelled passthrough hosts follow the same rules. Changes apply to new connections.
