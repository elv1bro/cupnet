Certificate CupNet MITM root CA for trusting HTTPS on phones or other browsers when they use this machine as an HTTP proxy. Inside CupNet the app trusts the CA automatically — you only need this file elsewhere.

MITM root CA

Subject: CupNet MITM CA (ECDSA P-256). Install on the device that sends traffic through CupNet’s proxy.

  • Use Mobile Wi‑Fi proxy → host:8877 (your PC’s LAN IP), then install this CA on the device.
  • Security Treat this CA like a password — anyone who trusts it can intercept TLS for you.
